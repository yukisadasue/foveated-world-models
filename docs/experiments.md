# LaWAM Stage 1の実験計画

実験は未実施。目的は、中心・周辺視野によってIDMの潜在行動表現とLaWMの条件付き未来特徴予測を改善すること。Stage 2の学習・閉ループ制御評価は本計画に含めない。

## Phase 0：基準実装と評価条件

LaWAMの論文v2、公開実装・重み・設定のコミットを固定する。DINO凍結、IDMとLaWMの同時学習、特徴MSE・補助状態MSE・KL正則化を確認し、基準を再現する。補助状態ラベルがないサンプルの処理、データごとの状態定義と正規化を確認する。

最初は手先状態付きロボット動画の限定データで比較する。人間動画の追加は、補助損失の適用条件を確定してから別条件として評価する。限定データの実験を元論文の事前学習全体の再現とは呼ばない。

- 学習・検証・テストは軌跡単位で分割し、近隣フレームの漏洩を防ぐ。未見背景・物体・視点も用意する。
- データ量、計算予算、独立seed数、予測時間幅を実験前に固定する。フレーム数だけでなく物理時間を合わせる。
- 入力解像度にかかわらず、全方式の評価対象を同じ未来DINO特徴マップに固定する。
- 評価用の背景・物体・手先・接触周辺のマスクと状態は予測器の入力に使わない。接触領域の定義・ラベルの信頼性を記録する。
- GPUの種類・VRAM・台数を確定してから規模と所要時間を見積もる。

## Phase 1：コピー予測への偏りの診断

現在特徴のコピーと基準Stage 1を比較する。IDMは正解の現在・未来特徴からzを推定し、LaWMは現在特徴とzから未来特徴を出力する。

| 指標・介入 | 確認すること |
|---|---|
| 全体・背景・物体・手先・接触周辺の領域平均MSE | 全体誤差に局所の失敗が隠れているか |
| 領域面積、全体損失への寄与、共有パラメータへの領域別勾配ノルムと方向 | 面積の偏りと学習の偏りを区別できるか |
| コピー基準に対する領域別改善量 | 未来を予測することで実際に得られる利益 |
| 予測変化（予測未来−現在）と正解変化（正解未来−現在）の大きさ・誤差 | 動きを過小予測しているか |
| 同一モデル内でzをゼロ化・入れ替え | 正しいzを使ったときに予測が改善するか |
| 手先状態の補助予測誤差 | zが身体運動の情報を保持しているか |

zの介入は分布外入力になり得る。性能低下だけで因果的な運動表現の獲得を断定せず、正規条件と併記する。物体移動量と予測時間幅で層別化し、動かない例だけで良い値が出ていないか確認する。

## Phase 2：中心・周辺視野の構造比較

まず基準IDMを固定してLaWM側を変更し、次にIDM側の変更と共同学習を評価する。基準側にも同じ追加学習予算を与え、初期重みの有利不利を揃える。

| 比較方式 | 切り分ける要因 |
|---|---|
| 基準Stage 1 | 元のIDM・LaWM・全損失を保った基準 |
| 一様な低解像度／高解像度 | 解像度だけの効果 |
| ROI重み付き損失のみ | 構造変更が必要か |
| 固定crop／ランダムcrop＋全体 | 局所入力を足すだけの効果 |
| 同容量の通常Transformer | パラメータ増加の効果 |
| 適応中心視野＋周辺視野（LaWM側のみ） | 予測器への選択的計算配分の効果 |
| 適応中心視野をIDM側のみ／両側へ導入 | 潜在行動推定と未来特徴予測それぞれの寄与 |
| 周辺視野・座標情報を個別に除去 | 全体文脈と座標対応の必要性 |

DINO、データ、予測時間幅、評価特徴を共通にする。計算量、パラメータ数、更新数を個別に報告し、同計算予算での比較を主評価にする。基準の補助状態損失とKLを維持し、それらの除去実験は別枠にする。

現在観測から選ぶROIを基本条件とする。正解ROIや未来由来のROIは上限診断として区別し、主結果に混ぜない。局所cropの未来教師は現在側で選んだ座標で切り出し、未来対象を追った教師cropとの混同を避ける。

## Phase 3：潜在行動表現と汎化

- 凍結したzに同容量の小型プローブを学習し、保持データで手先変化などを評価する。訓練中の補助ヘッドの適合度と分ける。
- 外観を変えて同じ運動を保つ評価では、zの安定性と運動情報の保持を両方測る。一定値のzによる見かけの不変性を除く。
- 未見の背景・物体・視点で領域別予測とコピー基準との差を測る。
- カメラだけ移動、物体だけ移動、両方移動を分ける。2D画像変換と3D視点移動は別条件にする。

異なるIDMが生成するzを直接交換しない。同一モデル内の介入と、共通の下流プローブ・未来特徴で比較する。単一の記録未来を用いた再構成能力の改善を、未来の選択能力の改善と解釈しない。

## Phase 4：計算費用と判断

学習時はDINO、ROI、IDM、LaWM、補助ヘッドを含むGPU時間・ピークメモリ・処理量を計測する。条件付き予測時は、zが与えられたLaWM単体と、現在画像のDINO・ROI処理を含む経路を分け、batch 1のp50/p95遅延を報告する。教師zを生成するIDMの費用も別記する。特徴の事前計算による高速化をオンライン経路の高速化とは扱わない。

- コピーへの偏りが見られない：崩壊を前提にせず、局所精度と計算効率の仮説を評価する。
- 損失重み付けだけで同等：中心・周辺視野構造の必要性を見直す。
- 未来情報を使ったROIでしか改善しない：現在観測からの選択方法を見直す。
- 再構成だけ改善し、zの運動情報が改善しない：予測器改善に主張を限定する。
- ROI推定費用が節約を上回る：計算効率の主張を見直す。
- 未見視点で改善しない：カメラ頑健性の主張を外す。

主結果は複数の独立学習seedのばらつきを含める。画像デコードによる可視化は補助資料とし、評価は共通DINO特徴と状態情報に基づく。
