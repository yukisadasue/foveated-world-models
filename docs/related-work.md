# 重点関連研究

本文と公式実装を参照した研究ノート。以下は移植済みの手法や確定した新規性を示すものではない。基礎のDiffusion Forcingを除き2026年公開。

| 論文 | 予測器に関する要点 | 今回の比較点 |
|---|---|---|
| [LaWAM](https://arxiv.org/html/2606.15768) | 潜在行動から未来の空間特徴を予測し、行動expertへ渡す | 基準アーキテクチャ |
| [DiLA](https://arxiv.org/html/2605.15725) | 動き・構造と外観・内容記憶を分離して未来特徴を融合予測 | 内容保持と動き予測の分担、Mamba記憶 |
| [Mem-World](https://arxiv.org/html/2606.18960) | 幾何・時刻に対応した履歴を検索し多視点世界予測を条件付け | 遮蔽、視点移動、記憶検索 |
| [DVG-WM](https://arxiv.org/html/2606.32028) | 粗い動き予測と高解像度の細部生成を分離 | 粗密表現と予測費用 |
| [WING](https://arxiv.org/html/2610.03607) | カメラ由来の変化と相互作用を分離して潜在行動を学習 | カメラ運動と操作の区別 |
| [Diffusion ReRoll](https://arxiv.org/html/2607.19919) | 時間区間を再ノイズ化し他区間の文脈で予測を修正 | 未来列の整合性と反復費用 |
| [LingBot-VA](https://arxiv.org/abs/2601.21998) | 自己回帰拡散で動画・行動を共同予測し実観測を戻す | 閉ループ予測更新 |
| [Diffusion Forcing](https://arxiv.org/abs/2407.01392) | 時刻ごとの独立ノイズ水準で系列を学習・生成 | 長期予測と誤差蓄積の基礎 |
| [LeWM](https://arxiv.org/html/2603.19312) | エンコーダと行動条件付き予測器を共同学習し潜在空間で計画 | 固定エンコーダ方式との違い |
| [PointACT](https://arxiv.org/abs/2605.21414) | 行動expert内で複数スケールの点群特徴を利用 | 局所幾何と行動生成の接続 |

DiLA、DVG-WM等との違いとして「操作に応じてどこへ計算を配分するか」を検討する。ただし、中心視野・能動視覚・ROI予測・動き重視損失の先行研究を追加調査するまで、新規と断定しない。

## LaWAMの区別しておくべき構成

LaWMは世界モデル部分、LaWAMは方策全体。

1. Stage 1：凍結DINOv3の現在・未来特徴から潜在行動エンコーダがzを得る。世界モデルは現在特徴とzから未来特徴を予測する。特徴MSE、補助状態予測、KL正則化で学習。
2. Stage 2：Qwen3-VL由来VLMが現在画像と指示からzを予測する。LaWMは未来特徴を生成し、Alternate-DiT行動expertが意味情報と現在・未来特徴から行動を出す。
3. DINOv3と教師潜在行動エンコーダは凍結。世界モデルは未来損失で更新するが、行動損失の勾配は未来特徴の枝で遮断する。

論文Appendix EではQwen3-VL先頭16層、DINOv3 ViT-B/16を使用。公開実装はQwen3-VL-2B-Instructを指定。現在の公開推論コードではVLMに補助視点を渡せるが、LaWM用の視覚入力は主画像リストの先頭を選ぶ。これは全視点の未来を共同予測する構造とは異なる。実装着手時にはコードのコミットを固定して再確認する。
