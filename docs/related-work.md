# Stage 1の基準と重点関連研究

## LaWAMのStage 1

基準資料は[LaWAM論文v2](https://arxiv.org/html/2606.15768v2)と[公式実装](https://github.com/RLinf/LaWAM)。以下は論文の記述であり、本リポジトリでの再現結果ではない。取得したコードはコミット `c12168d9077edea67fe7c1b70d08b80b8e65a9c8` に固定した。論文の記述と公開コードの層数・損失・時間幅などの違いは[セットアップ資料](stage1-setup.md)を参照。

| 構成 | 入力 | 出力・役割 |
|---|---|---|
| 凍結DINOv3 ViT-B/16 | 現在・未来画像 | 空間的な視覚特徴 u、u_T |
| IDM（潜在逆動力学エンコーダ） | u、u_T | 潜在行動の事後分布 q(z｜u,u_T) |
| LaWM（順方向デコーダ） | u、z | 未来視覚特徴の予測 |
| 補助状態予測器 g | 現在の手先状態 s、z | 未来の手先状態 s_T |

IDMとLaWMはStage 1で同時に学習する。zは実際のロボット指令そのものではなく、観測間の変化を説明する潜在表現。LaWMの視覚予測対象はDINO特徴で、RGB画素ではない。ただし学習信号には手先状態の補助予測も含む。

[§3.2・式4](https://arxiv.org/html/2606.15768v2#S3.SS2)の目的関数は、未来特徴MSE＋手先状態MSE＋潜在行動のKL正則化。補助状態予測器はStage 1後に破棄する。異なる身体の状態定義には軽量MLPヘッドを用いる（Appendix E.2）。

[§4](https://arxiv.org/html/2606.15768v2#S4)ではStage 1に約3,000時間のロボット動画と約1,500時間の一人称人間動画を使用。[Appendix E.6](https://arxiv.org/html/2606.15768v2#A5.SS6)では予測時間幅をロボット動画1.2秒、人間動画0.4秒とする。公開コードでは身体ID 0の人間サンプルを補助状態損失から除外し、ロボットの有効状態次元に損失を適用する。本リポジトリの初期ローダは状態付きロボットデータのみ対応する。

名称の区別として、LaWMは世界モデル部分、LaWAMはVLAを含む方策全体。Stage 2では凍結IDMを教師として、現在観測と言語からzを予測するPolicy Priorを学ぶ。今回の研究対象はStage 1であり、Stage 2の構成改良は扱わない。

## 背景への偏りに関する既存の証拠

LaWAMの[Appendix C](https://arxiv.org/html/2606.15768v2#A3)は、500本のLIBERO軌跡で予測特徴が初期特徴から離れ、正解未来に近いことを示している。したがって、モデル全体が単純コピーへ崩壊していることを前提にしない。一方、この集計だけでは背景・物体・接触周辺の領域別精度は判定できない。

本研究では、この全体評価に対して領域別のコピー基準、予測変化量、zへの依存を調べる。凍結DINO特徴の予測、補助状態損失、潜在行動のKLを含む実際のStage 1を診断する。

## 重点比較

背景と動きの分離、外観と構造の分離、空間的な計算配分は別々の設計軸。次の研究を比較の出発点とする。論文の主張を独立再現したものではなく、網羅的な先行研究調査でもない。

| 研究 | アプローチと貢献 | 今回との比較点 |
|---|---|---|
| [Iso-Dream（2022）](https://proceedings.neurips.cc/paper_files/paper/2022/file/9316769afaaeeaad42a9e3633b14e801-Paper-Conference.pdf) | 制御可能な動き・制御不能な動き・静止成分を分離。逆動力学で制御に関係する表現を学び、動画背景を含む制御や動画予測で評価 | ダイナミクスの分離。空間的な中心・周辺視野配分とは異なる |
| [DiLA（2026）](https://arxiv.org/html/2605.15725) | 構造の未来予測と外観の記憶を分けて融合。生成品質、行動転移、視覚計画、構造と外観の組替えで評価 | IDM・順方向予測と情報分離の関係。今回の最重要比較候補 |
| [DVG-WM（2026）](https://arxiv.org/html/2606.32028) | 低解像度の動き生成と高解像度の細部復元を段階化。動画品質と生成費用を改善 | 粗密処理の効果。ただし領域ごとの解像度配分やDINO未来予測とは異なる |
| [WING（2026）](https://arxiv.org/html/2610.03607) | カメラ変動と相互作用を分離し潜在行動へ蒸留。カメラ感度・行動情報とロボット転移を評価 | カメラ移動に引っ張られない潜在行動。静止背景のコピー問題とは区別 |
| [Artificial Foveated Perception（2026）](https://arxiv.org/html/2607.10655) | 操作に重要なマスクを補助信号として方策の注意を誘導し、環境変化への汎化を改善。推論時は追加モジュール不要 | ROI重み付き学習との比較。方策の背景依存への対策であり、Stage 1の未来予測の検証ではない |
| [Active Visual Fixation](https://avf-icra.github.io/) | 注視中心を高精細、周辺を粗く表現し、注視位置と注視座標での操作を学習。精密な実機操作を評価 | 中心・周辺視野と座標対応の先行例。公開プロジェクトページに基づく確認で、世界モデルの未来予測は対象外 |

## 新規性として検証すべき点

背景分離、中心視野、粗密表現を導入すること自体を新規性としない。Stage 1の共通未来特徴を予測する条件で、次を実験により確かめる。

- 基準の全体誤差では隠れる局所変化の予測失敗があるか。
- ROI重み付き損失や固定cropより、適応的な中心・周辺視野が有効か。
- 改善がIDMの潜在行動表現、LaWMの予測構造、計算量増加のどれによるか。
- 未来由来zによる再構成能力と、運動情報の保持・外観変化への汎化が両立するか。

先行研究との差と有効性が確認されるまでは、これらを研究仮説として扱う。
